# Security Policy

## Supported Versions

Security updates are applied to the latest minor version of each published package.

| Package | Supported |
| ------- | --------- |
| `gmana` | :white_check_mark: |
| `gmana_*` | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security issue or vulnerability within any package in this workspace, please report it privately:

1. **Do not create a public GitHub issue.**
2. Send an email describing the vulnerability, affected package(s), proof of concept, and potential impact to the maintainers, or open a private security advisory on GitHub under the **Security** tab.
3. You will receive an acknowledgment within 48 hours.
4. Maintainers will coordinate a patch and release a security advisory once a fix is verified.
